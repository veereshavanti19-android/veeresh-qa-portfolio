ABOUT ME

Quality is not a final step. It is a mindset.

I am a QA Engineer focused on finding defects before they reach the user and helping teams deliver software that is reliable, secure and production-ready.

My testing approach combines manual testing, API validation, mobile testing, automation, performance testing and security testing.

I enjoy understanding how a system works, identifying its risks and designing test scenarios that challenge both expected and unexpected behaviour.
